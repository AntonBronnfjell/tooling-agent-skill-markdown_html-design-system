# html-design-system

Agent skill that teaches an AI to design all the components of an HTML/CSS design system.

## Layout

```
html-design-system/
├── SKILL.md       # entry point loaded by the agent
├── references/    # detailed guides (tokens, components, ...)
└── assets/        # templates and starter files
```

## Install (Claude Code)

```bash
ln -s "$PWD/html-design-system" ~/.claude/skills/html-design-system
```
