# Security

## What this skill runs on your machine

| Component | When it runs | What it does | Network |
|---|---|---|---|
| `scripts/ds.py` | When the agent (or you) runs a command | Reads and writes files inside the design-system folder and the sync targets you configured. Never deletes files it didn't create (ownership ledger `.ds-owned.json`); `--dry-run` previews every write | Only `ds.py detect --url <url>`, which fetches the page you name and its stylesheets (read-only, no cookies, 2 MB / 20 files cap) |
| `PostToolUse` hook (`ds.py hook-post-edit`) | After each Write/Edit while the skill is active | Lints the edited file if it belongs to a design system; rebuilds `dist/tokens.css` when token JSON changes. Silent otherwise | None |
| `Stop` hook (`ds.py hook-stop`) | When the agent tries to end a turn | Only acts when a design system is in the `build` phase: blocks once per turn if components are missing. `"gate": "warn"` or `"off"` in `ds.config.json` softens or disables it | None |
| `mcp/server.py` (generated by `ds.py mcp`) | Only if you register it with an MCP client | Read-only stdio server over `dist/ds-index.json`, `llms/` and `DESIGN.md` | None |
| `install.py` / `install.sh` / `install.ps1` | Only when you run them | Copies or symlinks the skill into agent folders; `--claude-hooks` edits `~/.claude/settings.json` with a backup. The shell/PowerShell wrappers `git clone` this repository when not run from a clone | Only the optional clone |

- **No telemetry**, no analytics, no background processes. Python 3.8+ standard library only — no third-party packages are installed.
- Generated Storybook and CI files pin public npm packages (`storybook`, `@storybook/*`, `vite`); they're installed only when you run `npm install` yourself.

## Reporting a vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/AntonBronnfjell/tooling-agent-skill-markdown_html-design-system/security/advisories/new) rather than a public issue. Expect an acknowledgment within 5 business days.
